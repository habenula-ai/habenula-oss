# Contributors

Thank you to everyone who has contributed to Habenula.

This file records accepted community contributions. Each entry is one line, and
takes the form `- **@handle** — <type> · <full proposal URL>`.

The type says what the contribution was — a fix, a feature, docs, a
threat-model review, a bug report. It is recorded inline rather than as a
section heading, because the file is **strictly append-ordered, newest last**,
and the release tooling checks that property mechanically: a release only adds
lines to the end of this file, and it refuses to credit anything if an earlier
line changed. Adding an entry anywhere but the end, or reflowing an existing
one, makes that check fail.

Entries link the proposal in full. A bare cross-reference — a number sign
followed by a number — resolves against whichever repository it is read in, so
it is not a usable link here.

At the release that carries an accepted contribution, a commit authored by the
contributor adds their entry to this file. See
[CONTRIBUTING.md](CONTRIBUTING.md) for how that works and what reaches public
history.
